  3597→Les médicaments au Bénin portent deux types de codes principaux :
  3598→- EAN-13 : 13 chiffres — présent sur quasi tous les médicaments importés
  3599→- DataMatrix GS1 : encode GTIN + lot + date expiration via Application
  3600→Identifiers : (01)GTIN-14 (10)lot (17)YYMMDD (21)série
  3601→Le scan intervient dans 4 contextes :
  3602→1. POS_VENTE : ajout direct au panier avec lot FEFO
  3603→2. RECEPTION : pré-remplissage formulaire réception lot
  3604→3. INVENTAIRE : identification lot + saisie quantité réelle
  3605→4. VERIFICATION : interrogation alerte DPMED sur le lot
  3606→Deux types de matériel :
  3607→- Lecteur USB code-barres : envoie les chars comme un clavier,
  3608→se termine par Enter. Vitesse < 50ms entre caractères.
  3609→- Caméra smartphone/tablette : via API navigator.mediaDevices

  3633→TÂCHE 2 — UTILITAIRE GS1 (PARTAGÉ FRONT + BACK)
  3634→══════════════════════════════════════════════════════════════
  3635→Crée utils/gs1Parser.ts (utilisable côté client ET serveur) :
  3636→export interface GS1Data {
  3637→gtin? : string;
  3638→ean13? : string;
  3639→lot? : string;
  3640→expiry? : string; // YYMMDD brut
  3641→expiryDate? : Date;
  3642→serial? : string;
  3643→rawCode? : string;
  3644→}
  3645→export function parseGS1(raw: string): GS1Data {
  3646→// 1. EAN-13 : /^\d{13}$/ → gtin = '0' + raw, ean13 = raw
  3647→// 2. DataMatrix avec parenthèses : (01)xxx(10)yyy via regex
  3648→// /(\(\d{2,4}\))([^(]*)/g
  3649→// AI 01 → gtin, AI 10 → lot, AI 17 → expiry, AI 21 → serial
  3650→// 3. Format compact sans parenthèses : commence par '01' + 14 chiffres
  3651→// 4. Autres : retourner { rawCode: raw } pour résolution serveur
  3652→//
  3653→// Pour AI 17 : YYMMDD, si DD='00' → dernier jour du mois
  3654→// expiryDate = new Date('20YY-MM-DD')
  3655→}

  3657→TÂCHE 3 — HOOK useBarcodeInput (FRONTEND)
  3658→══════════════════════════════════════════════════════════════

  3661→Accumule les caractères dans un buffer.
  3662→Si délai entre deux chars < 50ms → lecteur USB → accumuler.
