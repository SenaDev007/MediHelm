     6→Guide d'Utilisation des Prompts
     7→1.1 Comment utiliser ce document
     8→Chaque prompt est prêt à être copié-collé directement dans Google Gemini (gemini.google.com) en sélectionnant le modèle Imagen. Les prompts sont rédigés en anglais — la langue la plus performante pour Gemini Imagen. Les commentaires en vert (lignes débutant par //) ne sont pas à inclure dans le prompt.
     9→1.2 Paramètres de génération recommandés
    10→1.3 Si le résultat n'est pas satisfaisant
    11→Ajouter en fin de prompt : 'photorealistic, professional photography, 8K resolution, sharp focus'
    12→Si le texte dans l'image est mal rendu : supprimer toute mention de texte et ajouter le texte en post-production (Figma, Canva).
    13→Si les personnages ne semblent pas africains : ajouter 'West African, Beninese, dark skin, natural African features'.
    14→Si la palette n'est pas respectée : ajouter 'color palette: teal green #1D9E75, dark teal #085041, white, minimal colors'.
    15→1.4 Post-production recommandée
    16→Compression : toutes les images doivent être exportées en WebP pour le web (qualité 85%).
    17→Dimensions finales : hero 1920×1080px, fonctionnalités 800×600px, avatars 400×400px.
    18→Ajouter les textes, logos et overlays dans Figma ou dans le code Next.js — jamais directement dans l'image générée.
    19→Harmoniser la luminosité et le contraste de toutes les images dans Lightroom ou GIMP pour une cohérence visuelle sur le site.
